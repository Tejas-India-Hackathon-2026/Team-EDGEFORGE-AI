# Roadmap

> **Current Phase:** Not started
> **Status:** Planning

## Must-Haves (from SPEC)

- [ ] **P0 Core Platform**: 4 heritage site selectors, 5 category filters, listing cards, 1-tap WhatsApp deep links (`wa.me`).
- [ ] **P0 Onboarding & Admin**: Self-service entrepreneur listing registration, clean admin toggle with approve/reject workflow, full `localStorage` persistence.
- [ ] **P0 Security & Architecture**: Zero-build single-file `index.html` with robust HTML input sanitization (XSS prevention).
- [ ] **P1 Visual Polish & Metadata**: Dynamic open/closed time calculations, static ratings (e.g. 4.8★), specialty tags, verified checkmark badges, Madhubani-inspired theme.
- [ ] **P2 AI Tourism Concierge**: Embedded chat, plain JS Netlify serverless function for Gemini API with Google Search Grounding & zero-fail local listings fallback.
- [ ] **Demo Readiness & Code Explanations**: 100% executable demo flow with plain-English code explanations for non-coder team members.
